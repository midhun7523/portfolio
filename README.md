# Midhun Balaji Perabattula — Portfolio Website

## 🚀 Features

* **Responsive Design:** Optimized for seamless viewing across desktops, tablets, and mobile devices.
* **Project Showcase:** Highlights key projects with live demo links, source code repositories, and feature breakdowns.

* **Interactive UI:** Dynamic UI elements, dark/light mode toggling, and modern transition animations.

⚡ Getting Started Locally
Prerequisites
Ensure you have Node.js and npm installed on your machine.

Node.js (v18.0.0 or higher)

npm (v9.0.0 or higher)

Installation
Clone the repository:

Bash
git clone {https://midhun7523.github.io/midhun-portfolio/}
Navigate to the project directory:

Bash
cd your-portfolio
Install dependencies:

Bash
npm install
Start the development server:

Bash
npm run dev
Open your browser and visit http://localhost:3000 (or the port specified in your terminal).

🌐 Deployment
This project is deployed using [Vercel / GitHub Pages / Netlify]. Any push to the main branch triggers an automated build and deployment pipeline.

To build the project for production manually:

Bash
npm run build
